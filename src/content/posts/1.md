## Default standards

### 1. Input
- standard input - file descriptor 0 - keyboard input

### 2. Output
- standard output - file descriptor 1 - display on screen by default
- standard error - file descriptor 2 - display on screen by default

## Operator

### 1. >
- command -> file
```bash
$ ls -l > file.txt          # saves the listing into file.txt
```

### 2. <
- feed a file into a command's input. command <- file
```bash
$ sort < names.txt          # sorts names in file names.txt
```

### 3. |
- pipe output into another command. command -> command
```bash
$ cat file.txt | grep "sword"
```
